# 1.2.28 Release Notes

Released: 2026-09-14

## Summary

`1.2.28` quiets an overly chatty log line and documents how Nuheat group away mode actually behaves.

## Highlights

- Setting a thermostat no longer writes the raw Nuheat update payload to the Homebridge log at info level on every change. The same information is now summarized at debug level, so normal logs stay readable
- The README and the Homebridge Config UI descriptions now explain that away mode is applied by Nuheat's servers, and that affected thermostats may be reported as being in **Standby** rather than showing an explicit Away state

## Upgrade Notes

- Existing Homebridge configurations remain compatible
- No configuration or accessory changes are required
- If you were relying on the info-level payload line for troubleshooting, enable the plugin's `debug` option to see the summarized setpoint update instead
