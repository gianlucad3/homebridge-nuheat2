# 1.2.27 Release Notes

Released: 2026-09-14

## Summary

`1.2.27` aligns the plugin's declared Homebridge support range with the required packaging rule so prerelease Homebridge installs are never blocked.

## Highlights

- `engines.homebridge` is now `>=1.8.0 <3.0.0-0`, which satisfies every Homebridge 1.x and 2.x release, stable and prerelease
- No `peerDependencies.homebridge` entry is declared, so npm cannot abort an install with `ERESOLVE` on a Homebridge prerelease
- `engines.node` is unchanged from `1.2.26`

## Upgrade Notes

- Existing Homebridge configurations remain compatible
- No configuration or accessory changes are required
- Works on Homebridge 1.8+ and all 2.x releases, including betas, on Node `^18.20.4 || ^20.18.0 || ^22 || ^24 || ^26`
