# 1.2.26 Release Notes

Released: 2026-07-09

## Summary

`1.2.26` adds Node.js 26 to the plugin's supported runtime range so Homebridge stops warning that `homebridge-nuheat2` is not compatible with Node v26.

## Highlights

- `engines.node` now includes `^26.0.0`, matching the Node range Homebridge 2.4 itself supports
- CI now runs the test matrix on Node 20, 22, 24, and 26
- Refreshed `@types/node` to the Node 26 type definitions

## Upgrade Notes

- Existing Homebridge configurations remain compatible
- No configuration or accessory changes are required
- Requires Homebridge 1.8+ and a supported Node runtime (`^18.20.4 || ^20.18.0 || ^22 || ^24 || ^26`)
